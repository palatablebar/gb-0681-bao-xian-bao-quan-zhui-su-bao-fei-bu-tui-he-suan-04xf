# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

# 家庭组合结算（m8_family）

一份家庭保单的成员共用一个保费折扣档。一名成员追溯减保后，全组在追溯期的标准保费规模下降，折扣档随之变化（样例：三档 8 折 → 两档 9 折）。组合按“组合键 + 追溯期 + 成员关系与原账单快照 + 规则版本”唯一裁决。

## 档位判定

按追溯期内全组标准保费合计（整数分）从高到低命中第一个满足下限的档位；档位越高门槛越高、折扣率越大，实缴比例 = 1 − 折扣率。组应收 = 组标准保费 × 实缴比例，四舍五入到分；再按各人标准保费占比用最大余额法分摊回成员，分摊回的各人新应收之和严格等于组应收（应收守恒）。

## 两条并列诉求的裁决口径

每位成员同时给出两条结论，使“同档成员同期应收一致”与“财务只给变动成员退费、不重开他人已寄账单”并存：

- 应收账（book）：所有成员按新档费率重算新应收，账面差额 = 新应收 − 原账单应收（负=应退，正=应补）。同档成员口径一致，组内可核。
- 现金账（cash）：仅触发更正的变动成员重开账单，现金补退 = 其账面差额；其余成员账单保持有效，现金补退恒为 0，账面差额全额计入“折扣挂账（非现金）”。

去向码：REFUND 退费（重开账单）、SUPPLEMENT 补缴（重开账单）、EVEN 持平（重开账单）、HOLD 折扣挂账（账单有效）、HOLD_EVEN 无差额（账单有效）。组口径满足差额守恒：账面差额合计 = 现金补退合计 + 折扣挂账合计。

## 唯一性、幂等与版本

- 唯一组合：对规范化输入（排序键 JSON）+ 规则版本取 SHA256 指纹；同一输入任意重排、重跑得到同一指纹与同一组合结果。
- 幂等：同一更正指纹在同一组合下只生成一个版本，重跑命中既有版本，不新增任何补退。
- 状态机：staged（已算待复核，变更已采信但整组金额待复核）→ active（复核通过、当前生效，每位成员均有明确去向）→ superseded（被新版替换，旧版留存可追溯）；active 可 close 结案冻结，冻结后禁止再开新版本。
- 替换原子性：新版先 staged，复核通过时在单事务内把当前指针由旧版切到新版并将旧版置 superseded；中途任何失败整体回滚，当前指针仍指旧版。
- 快照留存：成员关系与原账单在建立版本时整体冻结入库（family_versions.input_snapshot），逐人补退/挂账写入 family_ledger；源记录丢失仍可凭快照与每条结论携带的档位、费率、新旧账单依据解释整组结算。
- 结案文件：复核界面与下载接口对同一份当前生效结果调用同一 closing_csv 生成单份 CSV（运行清单/组合汇总/成员明细/守恒校验/档位依据），staged 阶段禁止下载（409 STATE）。
